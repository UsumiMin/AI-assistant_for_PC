# AI assistant for PC
## Описание проекта

Интеллектуальный голосовой ассистент для управления компьютером под управлением Windows. Ассистент распознаёт естественную речь, понимает контекст команд и выполняет действия на ПК - от открытия приложений до изменения системных настроек.

Проект может быть полезен в следующих сферах:
- Повседневное использование ПК (голосовое управление программами и файлами);
- Помощь пользователям с ограниченными возможностями (альтернативный способ взаимодействия);
- Автоматизация рутинных задач (создание файлов, очистка корзины, поиск в интернете).

## Основные функции
1. Голосовое распознавание - активация по ключевому слову "Афина", распознавание команд через Vosk.
2. Запуск приложений - открытие установленных программ по названию (браузер, блокнот, Telegram, Steam и другие).
3. Управление системой - очистка корзины, регулировка громкости, переключение раскладки клавиатуры, управление Bluetooth.
4. Поиск в интернете - открытие браузера с поисковым запросом.
5. Создание файлов - создание текстовых документов на рабочем столе.
6. Интеллектуальная обработка запросов - определение намерений пользователя с помощью MiniLM.
7. Поддержка сложных сценариев - при низкой уверенности подключается Qwen LLM для более точного понимания.
8. Веб-интерфейс - отображение субтитров и ответов ассистента в реальном времени.
9. Голосовой вывод - озвучивание ответов через Edge TTS (естественный женский голос).

## Технологии
1. Искусственный интеллект:
- MiniLM (paraphrase-multilingual-MiniLM-L12-v2) - лёгкая модель для классификации команд
- Qwen (Qwen2.5-1.5B-Instruct-GGUF) - мощная LLM для сложных запросов
- Llama.cpp - оптимизированный раннер для GGUF-моделей
2. Распознавание речи: Vosk (офлайн, русский язык)
3. Синтез речи: Edge TTS (естественный голос)
4. Бэкенд: Python, asyncio, WebSockets
5. Фронтенд: Electron, HTML, CSS, JavaScript
6. Взаимодействие с ОС: Win32 API, PowerShell, pyautogui

## Установка и запуск
Клонируйте репозиторий:

git clone https://github.com/your/ai-assistant

cd ai-assistant

По желанию можно заранее загрузить архив с моделями и распаковать его в папку:

https://drive.google.com/drive/folders/1iSkYso06v2If6uDZ6PD9CL4KOviUDoPZ?usp=sharing

Запустите скрипт первоначальной настройки:

install.bat

Дождитесь установки всех зависимостей (модели скачаются автоматически, если вы не сделали это раньше).

Для быстрого запуска используйте:

start.bat

## Пример использования
Скажите: "Афина" (ассистент активируется).

Произнесите команду, например:

- "открой стим" - запустит приложение
- "создай файл" - создаст текстовый документ на рабочем столе
- "найди фото котов" - откроет браузер с поиском
- "увеличь громкость" - изменит системную настройку
- "как дела?" - ассистент поддержит разговор

Ассистент выполнит команду и озвучит ответ, а в интерфейсе появятся субтитры.
